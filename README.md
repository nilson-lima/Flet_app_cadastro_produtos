# Cadastro App

Aplicativo de cadastro de produtos desenvolvido em Python, utilizando [Flet](https://flet.dev/) para a interface gráfica e SQLAlchemy + SQLite para persistência dos dados.

Projeto feito para fins de estudo, acompanhando um tutorial em vídeo no YouTube, com o objetivo de treinar e aprender na prática o uso dessas tecnologias.

## Baseado no tutorial

Este projeto foi desenvolvido seguindo o vídeo do canal Pythonando, disponível em: https://youtu.be/GSRg2EHyhZs

## Funcionalidades

- Cadastro de produtos (título e preço)
- Listagem dos produtos cadastrados
- Feedback visual de sucesso/erro ao salvar
- Persistência dos dados em banco SQLite

## Tecnologias

- [Python](https://www.python.org/)
- [Flet](https://flet.dev/) — framework para interfaces gráficas
- [SQLAlchemy](https://www.sqlalchemy.org/) — ORM para o banco de dados
- SQLite

## Sobre este projeto

Este é um projeto de estudo, criado para praticar:
- Componentes visuais com Flet (TextField, Container, ListView)
- Integração com banco de dados via SQLAlchemy
- Tratamento de erros com try/except
